# 2과 · 미션 규칙과 멀티플레이

서버가 마지막 코어를 확보한 순간에 팀원이 접속합니다. 이미 끝난 미션의 진행도는 보여 주고, 완료음은 그 순간을 본 사람에게만 들려주고 싶습니다.

## 판정과 전달 나누기

코어 ID의 집합은 이번 판에서 확보한 대상을 기억합니다. 목표가 두 개일 때 A, A, B, B가 들어오면 확보 개수는 1, 1, 2, 2입니다. 새 참가자에게 필요한 값은 현재 개수와 미션 단계입니다. 과거 알림을 놓쳤더라도 이 두 값을 읽으면 목표를 표시할 수 있습니다.

## 읽고 풀기

1. [코어 확보 함수](UE5_Content_Programming_Workbook.md#2)를 손으로 실행하고 진행·무시·완료가 언제 반환되는지 적습니다.
2. [상태 복제와 중도 합류](UE5_Content_Programming_Workbook.md#3)와 [네트워크 위키](../09-network-sync/index.md)를 읽습니다. 로컬 화면이 먼저 준비된 경우와 서버 값이 먼저 도착한 경우를 각각 그려 보세요.
3. [상점 구매 재시도](UE5_Content_Programming_Workbook.md#5)와 [관전·리플레이·핑·튜토리얼·보스](UE5_Content_Programming_Workbook.md#9)로 적용 범위를 넓힙니다.

**확인 문제**　미션 상태가 완료인데 화면을 다시 열 때마다 완료음이 들립니다. 보상도 중복 지급됐다고 할 수 있을까요?

**풀이**　지급과 소리는 다른 경로를 거칩니다. 서버 지급 기록부터 확인하세요. 화면은 현재 상태로 복원하고, 소리는 완료 전이가 일어난 순간에 재생하도록 구분합니다.
