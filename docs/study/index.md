# 학습

UE5 C++ 클라이언트 프로그래머의 필기 테스트와 기술 면접을 준비하는 학습지 모음입니다. 위키가 주제별로 찾아보는 자료라면, 학습지는 처음부터 끝까지 풀어 보며 공부하는 문제집에 가깝습니다.

## 학습지 사용법

주제 하나를 60~90분 단위로 공부합니다.

1. **읽기:** "핵심"과 "흔한 함정"을 한 번 읽고 화면을 덮습니다.
2. **안 보고 설명하기:** 면접 질문 3개에 소리 내어 답한 뒤 "답 요지 보기"를 펼쳐 비교합니다. 빠진 부분을 표시해 둡니다.
3. **코드로 확인하기:** 실습 과제는 결과를 먼저 예측해서 적고, 그다음 실행해 비교합니다.
4. **카드 등록:** 간격 반복 카드를 1일, 3일, 7일, 14일 뒤에 다시 봅니다.

각 주제 위의 체크 칸으로 진행 단계를 표시할 수 있고, 왼쪽 목차에 진행률이 나옵니다. "필기 대비 문제"는 먼저 종이에 답을 쓰고 "정답과 풀이 보기"를 펼친 뒤, 맞힘과 틀림을 표시합니다. "틀린 문제만" 버튼으로 오답만 다시 풉니다.

## AI 질문 패널

본문에서 모르는 부분을 드래그하면 "이 부분 질문하기" 버튼이 나옵니다. 질문은 그 구절과 노트 전체를 맥락으로 묶어 만들어집니다.

- 이 사이트에서는 페이지가 AI를 직접 부를 수 없습니다. 그래서 "질문 복사"를 누르고 Claude나 ChatGPT에 붙여 넣은 뒤, 받은 답을 패널에 붙여 넣어 대화에 남깁니다.
- 대화, 체크 표시, 카드·문제 표시는 **지금 쓰는 브라우저에만** 저장됩니다. 다른 PC나 다른 브라우저로 옮기면 진행 상황이 따라오지 않습니다.

## 공개본에 대해

이 학습지는 개인 노트에서 개인 프로젝트의 코드 위치와 검토 메모를 걸러 낸 공개본입니다. 엔진 동작의 근거는 UE 5.8 엔진 소스 위치(`Engine/Source/` 기준)로 남겨 두었습니다.
