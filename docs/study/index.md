# 게임 프로그래머 학습실

협동 FPS 한 판을 따라가며 C++ 기초, 언리얼의 게임 규칙, 화면에 보이는 결과를 연결합니다. 처음 공부한다면 1과부터 읽으세요. 복습할 때는 지금 설명하기 어려운 질문에서 시작하면 됩니다.

| 과정 | 답해 볼 질문 |
|---|---|
| [1과 · 객체와 데이터의 수명](foundations.md) | 캐릭터가 사라져도 점수는 어떻게 남을까요? |
| [2과 · 미션 규칙과 멀티플레이](systems.md) | 두 사람이 같은 코어를 밟으면 누가 완료를 판정할까요? |
| [3과 · UI와 플레이어 입력](interface.md) | 메뉴를 닫은 버튼이 왜 사격까지 일으킬까요? |
| [4과 · 성능 측정과 오류 추적](diagnostics.md) | 적이 많을 때 어느 작업에서 프레임이 늦어질까요? |

각 과정에는 게임 사례, 읽을 절, 풀이가 있습니다. 면접을 준비할 때는 각 과의 질문에 먼저 답한 뒤 풀이와 비교하세요.
