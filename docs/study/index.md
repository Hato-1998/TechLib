## 어디서 시작할까?

낯선 코드를 읽는 데 시간이 오래 걸리면 1과부터 시작하세요. 기능 구현 경험이 있다면 2과에서 프레임률을 바꿔 같은 움직임을 재현하거나, 6과에서 기존 콘텐츠를 다른 사람이 추가할 수 있게 만들어 보세요. 익숙한 FPS에서 먼저 풀었다면 두 번째 시도에서는 장르를 바꿔 어떤 가정이 달라졌는지 적습니다.

## 종합 실습 · 턴제 전술 게임의 이동 명령

격자 한 칸 이동을 입력받아 캐릭터를 움직이고, 도착한 뒤 행동력을 한 번 차감하세요. 처음에는 장애물 한 개와 유닛 한 개면 충분합니다.

1. 명령을 읽는 곳부터 위치와 행동력이 바뀌는 곳까지 추적합니다. 타일 좌표와 화면 좌표를 구분합니다.
2. 이동 중 취소, 이미 점유된 칸, 빠른 연속 입력의 규칙을 정합니다. 같은 입력으로 결과를 다시 확인할 수 있게 합니다.
3. UI가 목표 칸과 남은 행동력을 표시하게 합니다. 패드로 명령을 취소하고 이전 유닛으로 포커스가 돌아오는지 확인합니다.
4. 유닛 수를 늘려 같은 맵에서 측정합니다. 변경 전후 데이터, 회귀 검사, 다음 담당자가 이동 비용을 바꾸는 방법을 남깁니다.

**복습 기준**　‘원리를 설명했다’, ‘익숙한 예제에서 재현했다’, ‘다른 장르의 기존 코드에서 고치고 근거를 남겼다’를 구분해 기록하세요. 마지막 단계에서는 동료가 재현 절차만 보고 같은 결과를 얻을 수 있어야 합니다.
