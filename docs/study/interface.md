# 3과 · UI와 플레이어 입력

상점 목록을 빠르게 스크롤하자 새 상품 카드에 이전 상품의 아이콘이 뜹니다. 위젯은 살아 있고 로딩도 성공했습니다. 무엇이 어긋났을까요?

## 화면이 지금 가리키는 대상 확인하기

카드가 A를 표시할 때 보낸 요청이 B로 재사용된 뒤 끝날 수 있습니다. 결과를 적용하기 전에 요청 당시의 대상이나 세대 번호를 현재 카드와 대조합니다. 같은 원리는 체력 바에도 적용됩니다. 막대를 그리는 데 쓰는 값과 그 값을 바꾸는 경로를 함께 확인해야 합니다.

## 읽고 풀기

1. [미션 정의와 비동기 아이콘](UE5_Content_Programming_Workbook.md#6-b-a)에서 요청과 완료 순서를 그립니다. 로딩이 멈추는 문제는 [스트리밍 위키](../08-memory-management/index.md)에서 이어 봅니다.
2. [체력 바와 MVVM](UE5_Content_Programming_Workbook.md#7-umgmvvm-hp)의 함수에 50/100과 50/200을 넣고 변경 통지가 필요한 필드를 모두 적습니다.
3. [패드 포커스와 설정 취소](UE5_Content_Programming_Workbook.md#8)에서 버튼을 누른 화면과 뗀 화면을 구분합니다.

**확인 문제**　확인 버튼으로 옵션을 닫았는데 총이 발사됐습니다. 어떤 기록을 남길까요?

**풀이**　누름·해제 시각, 그때의 활성 화면과 포커스, 입력을 처리한 대상을 기록합니다. 실제 음량과 저장한 음량이 다른 문제라면 적용값·편집값·저장값을 따로 확인합니다.
